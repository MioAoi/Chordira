# Chordira

Font for displaying chords.  Based on Fira and Leland.

## License

This font inherits SIL Open Font License.

## Usage

For most common chords, typing as intuitively should trigger the desired shaping.

Other features include:

- Use period (0x2E) to break ligatures.  For example, for "dominant seventh on F-sharp", type `F#.7`, as  `F#7` would appear with the sharp sign combined with the number seven. _This is rather an ambiguity rooted in the notation practice itself, where it is understood by us human musicians that the 7 is always m7, hence the sharp must be modifying the root.  But for now, let the computer be stupid._

- `R1` thru `R7` gives caps roman numerals.  `r1` thru `r7` gives little ones.
